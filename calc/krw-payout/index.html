한국 통장엔 얼마 들어올까?

이베이 · 엣시 · 아마존 수수료부터 해외 수수료 · 환전 · 관세까지 다 빼고 계산해 드려요. 환율은 바뀌니까 「판매가의 몇 %가 통장에 들어오나」를 먼저 보여 드리고, 원화는 오늘 환율로 함께 계산해요.

이 계산기가 계산하는 방식

  • 이베이: 최종 판매 수수료(카테고리별, 대부분 13.6%) + 주문당 $0.40($10 이하 $0.30) + 해외 수수료 1.45%(한국 등록 셀러) → 미국 달러로 Payoneer 입금 → 원화로 출금할 때 1.2~4%. 셋 다 구매자 배송비 · 판매세까지 더한 총액에 붙어요. USD 로 팔아 USD 로 받으면 이베이 환전 수수료는 없어요.
  • 엣시: 등록비 $0.20 + 거래 수수료 6.5% + 결제 수수료 6.5% + $0.30(한국 셀러 — 미국 셀러 3% + $0.25 와 달라요) → Payoneer → 출금. 등록 통화가 USD 가 아니면 환전 2.5% 가 더 붙어요.
  • 아마존: 판매 수수료(카테고리별, 최소 수수료 적용) + 요금제 + FBA 배송비 → 원화로 받으면 Amazon Currency Converter 1.5%.
  • 순이익 = 원화 입금 − 원가 − 포장비 − 국제 배송비 − DDP 대행 수수료 − 관세(판매가 × 관세율 × 환율). 미국은 $800 소액 면세가 끝났고, 이베이는 한국 → 미국 배송에 DDP(관세 선납)를 요구해요.
  • 환율 손익분기 = 셀러가 원화로 내는 돈 ÷ (출금 뒤 남는 달러 − 관세 달러). 환율이 이 값 아래로 내려가면 순이익이 0 보다 작아져요.

계산에 넣지 않은 것

  • Payoneer 가 마켓에서 돈을 받을 때 수수료 — 공식 표에 「마켓마다 다름」이라고만 되어 있어 0 으로 뒀어요. 한국 은행 입금 수수료 · Payoneer 연회비($29.95, 12개월 수취 $6,000 미만일 때) 도 안 넣었어요.
  • 월마트 · 쇼피파이 · 틱톡샵 — 월마트는 한국 개인 셀러가 입점할 수 없고, 쇼피파이는 Shopify Payments 가 한국을 지원하지 않아요. 틱톡샵 US 는 미국 사업자 기준이라 뺐어요.
  • 아마존은 사업자 기준으로 계산했어요. 한국 개인(사업자 아님) 가입 가능 여부는 아마존에서 확인하세요.
  • 반품 · 프로모션 할인 · 이베이 스토어 요율 · 셀러 등급이 낮을 때 가산 수수료 · 부가세(수출은 영세율 대상이에요 — 사업자 기준, 세부는 국세청 126).
  • 결과는 예상치예요. 실제 정산은 각 마켓 정산서와 Payoneer 화면이 기준이에요.

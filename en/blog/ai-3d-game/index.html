Can AI make a 3D game
from one prompt?

Runs in your browser, nothing to install

Short answer. Yes. One English prompt, no coding, gave a playable 3D game. But only 2 of the 4 runs were playable right away (Gemini Carbon run 2 and the Claude Fable claude.ai run).

Every game below came from sending the same prompt exactly once, and the code is unchanged. Hit Play to open it in a new tab.

Play the 4 games

Use the keyboard on a computer and the on-screen buttons on a phone. On a phone, tap PLAY and a move joystick shows up bottom-left, with JUMP and DASH bottom-right.

📱 The phone buttons were added afterwards by Mikukjubu, not by the AI. The game code itself is exactly what the AI wrote.

무료 자료

내 사이트,
AI에 나올까?

돈 안 내고 직접 확인하는 복붙 프롬프트

손님이 챗GPT에 "근처 베이글 맛집 추천해 줘"라고 물었을 때 내 가게가 나오는지, 유료 도구 없이 직접 확인하는 방법입니다. 아래 프롬프트를 복사해서 [노란 칸]만 내 것으로 바꿔 쓰면 됩니다. 챗GPT·클로드·제미나이 세 곳에서 직접 돌려 보고 정리했습니다.

먼저, 규칙 3가지

RULE 1

내 이름은 빼고 묻기

"○○빵집 알아?"라고 물으면 AI가 검색해서 뭐든 찾아옵니다. 노출 여부는 손님이 할 질문으로만 봅니다.

RULE 2

3번 돌리기

AI 답은 물을 때마다 바뀝니다. 한 번 결과로 판단하지 말고 3번 중 몇 번 나왔나로 봅니다.

RULE 3

나를 모르는 상태로

평소 쓰던 채팅은 AI가 나를 기억합니다. 임시 채팅 + 개인화 끄기로 처음 보는 손님처럼 묻습니다.

직접 테스트해 보니

2026년 9월 25일, 같은 질문("서울 성수동에서 베이글 맛집 찾고 있어…")을 세 AI에 돌렸습니다. 셋 다 프롬프트대로 5곳과 출처를 내놨고, 이런 게 보였습니다.

  • AI가 참고한 곳은 가게 홈페이지가 아니었습니다. 다이닝코드·트리플·네이버 지도·카카오맵·식신·기사·블로그 후기처럼 남이 쓴 페이지가 출처였습니다. 작은 가게는 "웹사이트"로 인스타그램 주소가 나왔습니다.
  • 챗GPT 임시 채팅도 기본값은 기억을 씁니다. 첫 질문 전에 오른쪽 위 Personalized → Unpersonalized로 바꿔야 기억·맞춤 지침을 안 씁니다.
  • 제미나이는 같은 가게를 두 번 넣었습니다. 5곳이라 해도 실제로는 4곳이었습니다. 결과는 꼭 눈으로 확인하세요.
  • 클로드는 오래된 정보를 따로 표시했습니다("이 주소는 2023년 글 기준"). 틀린 정보를 찾을 때 쓸모 있습니다.

준비 1분 — AI별로 다른 것

질문 문구는 거의 같아도 됩니다. 다른 건 기억 끄는 법과 출처 보는 곳입니다.

AI기억 끄기웹 검색출처 보는 곳
챗GPT임시 채팅 → 첫 질문 전에 오른쪽 위 Unpersonalized 선택알아서 검색. 안 하면 프롬프트에 "웹에서 검색해서"답 속 출처 칩 + Sources 버튼
클로드오른쪽 위 유령 아이콘 Incognito무료도 가능. 필요하면 알아서 검색("Searched the web" 표시)문장마다 붙는 출처
제미나이New chat 옆 Temporary chat프롬프트에 "웹에서 검색해서"를 꼭 넣기답 속 출처 이름 / Sources 패널
퍼플렉시티Incognito기본이 검색모든 답에 출처 번호

지역 가게면 질문에 도시·동네 이름을 직접 넣으세요. 제미나이는 기본으로 내 위치와 구글 계정 주소를 참고해서, 이름을 안 넣으면 사는 곳에 따라 결과가 달라집니다.

복붙 프롬프트

①이 가장 중요합니다. 시간이 없으면 ①만 3번 돌려도 됩니다.

① 손님 질문으로 노출 확인
[내 지역]에서 [내 분야] 찾고 있어. 웹에서 검색해서 추천할 곳 5곳을 알려줘.
각 추천마다 이름, 웹사이트 주소, 추천 이유 한 줄, 참고한 출처 링크를 적어줘.

예: [서울 성수동]에서 [베이글 맛집] / [부산 해운대]에서 [반려견 동반 카페]. 내 이름은 넣지 않습니다.

①-b 블로그·온라인 가게용
[내 블로그 주제]에 대해 초보자가 믿고 볼 만한 블로그나 웹사이트 5곳을 웹에서 찾아서 알려줘.
각각 주소와 추천 이유 한 줄, 참고한 출처 링크를 적어줘.
② 손님 질문 넓히기
[내 분야]를 찾는 사람이 AI에게 실제로 물어볼 만한 질문을 10개 만들어줘.
"추천", "비교", "가격", "초보", "근처" 같은 여러 상황을 섞어줘.

나온 질문 중 3개를 골라 ①처럼 각각 새 임시 채팅에서 돌립니다. 손님마다 묻는 말이 다르니까요.

③ AI가 나를 제대로 아는지
[내 사이트 주소]에 대해 웹에서 찾아보고 알려줘.
1) 어떤 곳인지 두세 줄로 설명
2) 네가 참고한 페이지 주소 전부
3) 틀렸을 수도 있는 정보가 있으면 따로 표시

여기서부터는 내 이름을 넣습니다. 영업시간·가격·위치가 틀리게 나오면 그게 제일 먼저 고칠 것입니다.

④ 내 사이트 중 어떤 페이지가 쓰이나
[내 분야] 관련 질문에 답할 때 [내 사이트 주소] 안에서 인용할 만한 페이지가 있으면 주소를 전부 적어줘.
각 페이지가 어떤 질문에 쓸모 있는지 한 줄씩 적어줘. 찾지 못했으면 "없음"이라고 써줘.
⑤ 경쟁 가게와 비교
[내 지역]에서 [내 분야]를 찾는 사람에게 [내 사이트 주소], [경쟁 사이트 1], [경쟁 사이트 2] 중 어디를 먼저 추천하겠어?
웹에서 확인하고, 순서와 이유, 각 사이트에 대해 참고한 출처 링크를 적어줘.
⑥ 왜 안 나올까 + 고칠 점
①번 질문에서 [내 사이트 주소]가 추천에 안 들어갔다면(또는 뒤쪽이었다면), 추천된 곳들과 비교해서 이유로 보이는 점을 3가지만 알려줘.
그리고 내가 이번 주에 할 수 있는 개선 3가지를 쉬운 말로 적어줘. 추측인 부분은 "추측"이라고 표시해줘.

AI는 자기가 왜 그렇게 골랐는지 실제로는 모릅니다. 이 답은 그럴듯한 추측으로만 참고하세요.

⑦ 결과를 표로 정리
지금까지 이 대화의 답을 표로 정리해줘.
열: 질문 / 내 사이트 언급(예·아니오) / 내 사이트 링크(예·아니오) / 몇 번째 / 같이 나온 곳 / 인용된 내 페이지 주소 / 톤(좋음·보통·나쁨)
클로드용 압축 버전 (무료 사용량 아끼기) ▾

클로드 무료는 사용량이 5시간마다 초기화되고 검색이 사용량을 씁니다. 질문을 두 개로 줄인 버전입니다.

클로드 ① 손님 질문
웹 검색을 써서 답해줘. [내 지역]에서 [내 분야]를 찾는 사람에게 추천할 곳 5곳을 골라줘.
각각 이름, 주소, 추천 이유 한 줄, 근거가 된 출처를 달아줘.
검색으로 확인하지 못한 곳은 넣지 말아줘.
클로드 ② 내 사이트 확인 + 정리
웹 검색으로 [내 사이트 주소]를 찾아봐줘.
- 이 사이트가 무엇인지 두 줄 요약
- 실제로 열어본 페이지 주소 목록
- 찾을 수 없었던 정보는 "확인 못 함"이라고 적기
- 위 ① 결과에서 내 사이트가 덜 보인 이유로 보이는 점 3개와, 이번 주에 할 수 있는 개선 3개
추측으로 채우지 말아줘.
English version (미국 손님 기준으로 볼 때) ▾
① Customer question
I'm looking for [type of business] in [city]. Search the web and recommend 5 options.
For each one, give the name, website, a one-line reason, and the source link you used.
③ Does AI know my site?
Search the web for [my site URL]. Summarize what it is in 2–3 lines, list every page you looked at, and flag anything that might be wrong.

재미 버전 — 그래도 쓸모 있게

공유하기 좋은 버전입니다. 재미있지만 각각 점검하는 게 있습니다.

🎤 AI 기자 인터뷰 — AI가 나를 어떻게 소개하나
너는 동네 소식지 기자야. 웹에서 [내 사이트 주소]를 조사하고, 이 가게(블로그)를 소개하는 짧은 기사를 써줘.
제목, 한 줄 요약, 장점 2개, 아쉬운 점 1개, 참고한 링크를 넣어줘. 찾지 못한 정보는 지어내지 말아줘.
💘 AI 소개팅 — 3명 안에 내가 있나
너는 소개팅 주선자야. "[손님이 할 질문]"을 하는 사람에게 어울리는 [내 분야] 상대를 웹에서 3곳 찾아서 소개해줘.
각 후보의 매력 포인트, 주소, 출처 링크를 달아줘.

3곳 안에 내가 없으면 "왜 나는 소개 안 해 줬어?"로 이어서 물어보세요(⑥과 같은 효과).

🔥 쓴소리 모드 — 처음 온 손님 눈으로
[내 사이트 주소]를 웹에서 보고, 처음 온 손님 입장에서 솔직하게 놀려줘.
단, 웃기되 구체적으로: 헷갈리는 점, 찾기 어려운 정보, 경쟁 사이트보다 약한 점을 짚어줘. 마지막엔 고칠 점 3개로 정리해줘.
🌸 칭찬 모드 — 내 강점 찾기
[내 사이트 주소]를 웹에서 보고 이 곳의 진짜 강점 3가지를 찾아줘.
그리고 그 강점이 AI 답변에 더 잘 인용되려면 사이트 어디에 어떻게 써두면 좋을지 알려줘.
🕵️ 미스터리 손님 — AI는 어떻게 검색하나
너는 [내 지역]에 막 이사 온 사람이야. [내 분야]를 찾으려고 인터넷을 뒤지는 과정을 그대로 보여줘.
어떤 검색을 하고, 어떤 사이트를 열고, 최종적으로 어디를 고르는지 단계별로 적고 링크를 달아줘.

공식 무료 숫자도 있습니다

프롬프트는 "오늘 내 눈으로 본 표본"입니다. 실제 노출 숫자는 무료 공식 도구가 보여 줍니다.

  • 구글 서치콘솔 → 생성형 AI 보고서: 구글 AI 개요·AI 모드에서 내 페이지가 몇 번 보였는지
  • 빙 웹마스터 도구 → AI Performance: 마이크로소프트 코파일럿이 내 페이지를 몇 번 출처로 썼는지, 어떤 검색어였는지

솔직한 주의사항

  1. AI 답은 매번 바뀝니다. 같은 질문에 같은 목록이 나올 확률은 1%도 안 된다는 조사가 있습니다(SparkToro, 2026년 1월). 그래서 "여러 번 중 몇 번"으로 봅니다.
  2. 유료 추적 도구 데이터와는 다릅니다. 유료 도구는 매일 수십~수백 개 질문을 자동으로 돌립니다. 이건 직접 보는 점검입니다.
  3. AI가 가짜 링크를 만들 때가 있습니다. 링크는 직접 눌러서 열리는지 확인하고 적으세요.
  4. "왜 날 안 뽑았어?"에 대한 답은 추측입니다. AI는 자기 선택 이유를 실제로 알지 못합니다.
  5. 내 이름을 넣은 질문(③)은 "AI가 나를 정확히 아는가"만 봅니다. 노출 여부는 이름 없는 질문(①)으로만 판단하세요.

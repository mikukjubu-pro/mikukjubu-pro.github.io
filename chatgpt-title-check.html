질문 3개만 붙여넣으면 제목까지 고쳐 줘요

ChatGPT는 구글 순위가 아니라 손님이 묻는 질문 글자와 제목 글자가 얼마나 같은지를 보고 사이트를 자주 고릅니다. 제가 운영하는 작은 디지털 상품 사이트도 이렇게 제목을 바꾼 뒤 ChatGPT 추천 1번으로 나왔습니다. 그 과정을 클로드·제미나이가 대신 해 주는 무료 스킬로 만들었습니다. 돈 내지 않고, 아래 순서대로 복사·붙여넣기만 하면 됩니다.

# ChatGPT 추천 제목 체크 (미국주부 무료 스킬)

사용자는 블로그·온라인 가게를 하는 초보다. 쉬운 말로, 한 번에 한 단계씩 안내한다.
사용자가 붙여넣은 ChatGPT 답이 없으면 지어내지 않는다. 판정은 붙여넣은 내용으로만 한다.

## 왜 제목인가 (사용자가 물으면 설명)
- ChatGPT는 질문을 검색 문장으로 바꿔 웹을 찾고, 그중 **질문 글자와 제목 글자가 많이 겹치는 페이지**를 자주 인용한다.
  (AirOps 2026년 3월 연구, 질문 15,000개: 제목이 질문 단어를 절반 이상 같이 쓰면 인용률 20.1%, 10% 미만이면 9.3%.)
- 구글·네이버 순위와 따로 논다. 만든 지 몇 달 안 된 작은 사이트도 1위로 추천된 실제 사례가 있다.
- 순위는 물을 때마다 바뀐다. 한 번 결과로 판단하지 않는다.

## 1단계 — 정보 받기
사용자에게 아래 3가지만 묻는다. 이미 말했으면 다시 묻지 않는다.
1. 페이지 주소 (없으면 "아직 없음")
2. 지금 제목
3. 손님이 누구인가 — 한국 손님인가, 미국 등 영어권 손님인가

## 2단계 — 질문 3개 만들기
손님이 ChatGPT에 **실제로 칠 문장**을 3개 만든다.
- 손님 언어로 쓴다. 영어권 손님이면 영어로.
- 내 사이트 이름·브랜드는 넣지 않는다.
- 무료 자료면 "무료/free"를 넣는다. "free"가 없으면 ChatGPT가 웹 검색을 아예 안 하고 혼자 답하는 경우가 많다.
- 3개는 서로 다르게: ① 가장 흔한 말 ② 더 좁은 말(연도·용도·대상) ③ 형식이나 상황이 붙은 말.

각 질문을 **따로따로 복사하기 쉬운 코드 상자**에 넣고, 아래 안내를 그대로 보여 준다.

> **ChatGPT에서 이렇게 해 주세요**
> 1. chatgpt.com 에서 **임시 채팅**을 엽니다. (로그인했다면 오른쪽 위에서 개인화도 끕니다 — 평소 대화 기억이 섞이지 않게)
> 2. 질문 하나를 붙여넣고 보냅니다. 답에 출처 링크가 없으면 **검색(지구본) 버튼을 켜고** 다시 보냅니다.
> 3. 답 아래 **복사 버튼**(네모 두 개 아이콘)을 누릅니다. 출처 링크까지 같이 복사됩니다. 화면 캡처를 붙여도 됩니다.
> 4. 여기에 붙여넣습니다. 질문마다 **새 임시 채팅**에서 반복합니다.

## 3단계 — 판정
답이 하나 들어올 때마다 **기다리지 말고 바로** 그 질문의 판정 표를 보여 주고, 다음 질문 답을 붙여 달라고 한다.
사용자가 "이게 다야", "나머지는 못 했어"라고 하면 받은 답만으로 4단계까지 간다.

| 질문 | 내 사이트 나옴? | 몇 번째 | 대신 나온 곳 (상위 5) | 그곳들의 제목 모양 |
|---|---|---|---|---|

- "몇 번째"는 답에 나온 순서로 센다. 출처 목록만 있으면 출처 순서로 센다.
- 출처 링크가 하나도 없으면 "ChatGPT가 검색 안 함"으로 적는다. 이건 나쁜 신호가 아니다 — **아직 전용 페이지를 가진 곳이 적다**는 뜻일 수 있다. 질문에 free·연도·형식을 넣어 한 번 더 시켜 본다.
- 대신 나온 곳들의 제목에서 **공통 모양**을 찾는다. 예: `Free ___ Template (Google Sheets)` 가 여러 개면 그게 ChatGPT가 고르는 모양이다.
- 같은 모양의 전용 페이지가 이미 10개 가까이 꽉 찼으면 솔직하게 말한다: "제목만으로는 늦었을 수 있다 — 더 좁은 주제(연도·용도·대상)를 노리자."

## 4단계 — 제목 고치기
고친 제목 2~3개를 주고, 하나를 추천한다. 규칙:
1. **질문 글자를 그대로** 제목 앞쪽에 넣는다. 띄어쓰기·단어 순서도 질문과 같게.
2. 무료면 **Free/무료** + 물건 이름 + 형식(Google Sheets, PDF 등)을 다 넣는다. **유료 상품엔 Free를 넣지 않는다.**
3. 브랜드 이름은 맨 뒤에 둔다.
4. **한 물건 = 한 페이지.** 여러 상품을 한 페이지에 묶었으면 나누라고 말한다.
5. 페이지 첫 문단에 답을 쓴다 — 무엇인지, 무료인지, 이메일 필요 여부, 형식.

지금 제목이 이미 질문 단어를 거의 다 갖고 있으면 **억지로 바꾸지 않는다.** "제목은 이미 잘 맞아요"라고 말하고, 대신 이것부터 보라고 한다: 페이지가 공개돼 있나 · 새로 만든 지 며칠 안 됐나(검색에 들어가기까지 시간이 걸린다) · 아래 5단계 robots.txt · 첫 문단에 답이 있나.

전·후를 표로 보여 준다.

| | 제목 | 질문과 겹치는 단어 |
|---|---|---|
| 지금 | … | … / 질문 단어 수 |
| 추천 | … | … / 질문 단어 수 |

## 5단계 — 다음 할 일
1. 사이트에서 제목을 바꾼다 (블로그 제목 + 검색 제목(SEO 제목) 둘 다).
2. robots.txt 에서 **OAI-SearchBot 을 막지 않았는지** 확인한다. 막혀 있으면 ChatGPT 검색에 안 나온다.
3. **1~2주 뒤** 같은 질문 3개로 2단계부터 다시 잰다. 결과는 아래 표에 날짜와 함께 적어 두라고 한다.

| 날짜 | 질문 | 몇 번째 |
|---|---|---|

## 하지 말 것
- 순위를 약속하지 않는다 ("이렇게 하면 1위"). 연구는 관계를 본 것이지 보장이 아니다.
- 붙여넣지 않은 결과를 추측해서 채우지 않는다.
- 구글 순위부터 올리라고 하지 않는다. ChatGPT 추천과 따로 논다.

C. ChatGPT에 물어보기 (클로드·제미나이 똑같음)

4번 — 질문 하나를 ChatGPT에 넣기

  1. 새 탭에서 chatgpt.com을 엽니다.
  2. 오른쪽 위 임시 채팅(점선 말풍선 아이콘)을 켭니다. 로그인했다면 오른쪽 위에서 개인화도 끕니다 — 평소 대화 기억이 결과에 섞이지 않게요.
  3. 클로드·제미나이가 준 질문 ①을 복사해 붙여넣고 보냅니다.
  4. 답에 출처 링크가 하나도 없으면, 입력칸의 검색(지구본) 버튼을 켜고 다시 보냅니다.

5번 — 답 복사해서 다시 붙여넣기

  1. ChatGPT 답 맨 아래 복사 버튼(네모 두 개 겹친 아이콘)을 누릅니다. 출처 링크까지 같이 복사됩니다.
  2. 클로드·제미나이 창으로 돌아와 그대로 붙여넣고 보냅니다. 앞에 "질문 ① 답이야"라고 한 줄 붙이면 더 좋아요.
  3. 바로 판정 표가 나옵니다 — 내 사이트가 나왔는지, 몇 번째인지, 대신 어떤 사이트가 나왔는지.

6번 — 질문 ②, ③도 똑같이

질문마다 ChatGPT에서 새 임시 채팅을 열고 4~5번을 반복합니다. 시간이 없으면 "나머지는 못 했어, 이걸로 해 줘"라고 보내도 됩니다.

7번 — 고친 제목 받고, 2주 뒤 다시 재기

  1. 질문 글자에 맞춘 고친 제목과 전·후 비교표가 나옵니다. 제목이 이미 잘 맞으면 "바꿀 필요 없다"고 알려 줍니다.
  2. 내 블로그·상품 페이지에서 제목과 검색 제목(SEO 제목)을 바꿉니다.
  3. 1~2주 뒤 같은 질문 3개로 4번부터 다시 해서 순위가 바뀌었는지 봅니다.

직접 테스트해 보니 (2026년 10월 27일)

  • ChatGPT 답 아래 복사 버튼을 누르면 출처 링크까지 같이 복사됩니다. 그래서 붙여넣기만으로 몇 번째인지 셀 수 있습니다.
  • 질문 "free 2027 budget planner google sheets"(로그아웃·임시 채팅)에 제 사이트의 Free 2027 Budget Planner (Google Sheets) 페이지가 1번으로 나왔습니다. 질문 글자가 제목에 거의 그대로 있습니다.
  • 클로드에 스킬 zip을 올리고 "ChatGPT 추천 제목 체크해 줘"라고 하니 스킬이 바로 켜져 같은 순서로 진행했습니다. 제목이 이미 잘 맞을 땐 크게 바꾸지 말라고 판정했습니다.
  • 로그인 안 한 제미나이에 지시문을 넣고 손님처럼 써 보니 질문 3개 → 판정 표 → 제목 추천 → 다음 할 일까지 순서대로 나왔습니다.

솔직한 주의사항

  1. 순위는 물을 때마다 바뀝니다. 같은 질문에 1번이었다가 9번으로 내려간 적도 있습니다. 1~2주 뒤 같은 질문으로 다시 재서 흐름을 보세요.
  2. 제목은 많은 이유 중 하나입니다. 제목이 질문 단어를 절반 이상 같이 쓰면 인용률이 20.1%, 10% 미만이면 9.3%였다는 연구(AirOps, 2026년 3월)가 있지만 관계를 본 것이지 보장은 아닙니다.
  3. 무료 자료면 "Free·무료"를 꼭 넣으세요. "free"가 없는 질문엔 ChatGPT가 웹 검색을 안 하고 혼자 답하는 경우가 많았습니다. 유료 상품엔 넣지 않습니다.
  4. robots.txt에서 OAI-SearchBot을 막으면 ChatGPT 검색에 안 나옵니다(OpenAI 공식 안내).
